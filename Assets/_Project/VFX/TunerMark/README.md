# TunerMark VFX & Prefabs

Pasta de recursos e prefabs para o efeito visual da marca Crystal Tuner (T4).

- `TunerMark.prefab`: Runa de cristal com espiral de contagem regressiva flutuando sobre o inimigo.
- `TunerMarkShatterVFX.prefab`: Efeito de partículas da explosão de estilhaços cristalinos disparado ao consumir a marca.
